CONDO-SAFE24 - Instalacao no Render (rapido)

1) Suba este projeto para um repositorio no GitHub (Upload files ou git push).
2) No Render: New + > Web Service
3) Conecte o repo e selecione:
   - Environment: Python
   - Build Command: pip install -r requirements.txt
   - Start Command: gunicorn app:app

4) Em Environment Variables (Render):
   - SECRET_KEY = (uma senha grande 32+ caracteres)
   - CENTRAL_PASSWORD = (senha da portaria)
   - ADMIN_PASSWORD = (sua senha admin)
   - APP_TZ = America/Sao_Paulo

IMPORTANTE (CHAVES POR CONDOMINIO):
- Voce pode (opcional) definir CONDO_KEYS_JSON no Render.
- Mesmo se definir, as chaves geradas no Admin continuam funcionando (merge ativado).

5) Deploy.
