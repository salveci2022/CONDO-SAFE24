FAQ

Perguntas frequentes

Precisa instalar algum aplicativo? +
Não. O CONDO-SAFE24 funciona 100% pelo navegador do celular. O morador acessa o link, e pronto. Opcionalmente pode instalar como PWA (ícone na tela inicial) em 2 cliques.
Como os dados ficam protegidos? +
Cada condomínio tem uma chave exclusiva. Os dados são completamente isolados entre clientes. O sistema usa HTTPS, sessões seguras e proteção contra ataques brute-force.
Quantos moradores podem usar simultaneamente? +
Não há limite de acessos simultâneos. O sistema foi projetado para suportar todos os moradores acionando ao mesmo tempo sem degradação.
O sistema funciona sem internet? +
O botão de pânico precisa de conexão para enviar o alerta. O GPS funciona mesmo com sinal fraco. Em áreas sem cobertura, o alerta é enfileirado e enviado assim que a conexão retornar.
Como é feita a cobrança? +
Cobrança mensal automática via Hotmart. Aceita cartão de crédito, boleto e Pix. Cancele quando quiser sem multa ou fidelidade mínima.
Posso testar antes de contratar? +
Sim! Acesse /demo para ver o sistema completo funcionando com dados de demonstração. Nenhum cartão de crédito necessário para o teste.
