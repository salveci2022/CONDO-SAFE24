OBRIGATÓRIAS (sem estas o sistema não funciona em produção):
─────────────────────────────────────────────────────────────────

SECRET_KEY
  Gere: python -c "import secrets; print(secrets.token_hex(32))"
  Ex:   3f8a9c2d1e4b7f6a0c5d8e9b2a1f4c7d...

CENTRAL_PASSWORD
  Senha da equipe de monitoramento (central de segurança)
  Ex:   Central@Condo2026

ADMIN_PASSWORD
  Senha do administrador do sistema
  Ex:   Admin@SpyNet2026

VAULT_ENCRYPTION_KEY
  Chave AES-256 para cifrar dados pessoais — CRÍTICO
  Gere: python -c "import secrets; print(secrets.token_hex(32))"
  Ex:   a1b2c3d4e5f6...  (64 caracteres hexadecimais)
  ⚠️  SEM ESTA CHAVE OS DADOS DO VAULT SÃO ILEGÍVEIS APÓS RESTART

REVEAL_SECRET
  Código especial para revelar identidade de moradores (admin)
  Gere: python -c "import secrets; print(secrets.token_hex(16))"
  Ex:   9f2e4a8b1c3d5e7f
