INSTALACAO RAPIDA (Render)

1) Suba esta pasta (ou o ZIP) em um repositorio no GitHub.
2) No Render: New +  -> Web Service -> conecte o repositorio.
3) Configure:
   - Build Command: pip install -r requirements.txt
   - Start Command: gunicorn app:app
4) Em Environment (Render), defina:
   - SECRET_KEY = (use uma senha grande 32+ caracteres)
   - ADMIN_PASSWORD = (senha do admin)
   - CENTRAL_PASSWORD = (senha da portaria)

IMPORTANTE (chaves dos condominios):
- Nao defina CONDO_KEYS_JSON no Render, a menos que voce saiba o que esta fazendo.
- Se definir, o sistema agora faz MERGE com as chaves criadas no Admin.

5) Deploy -> aguarde -> teste:
   /login_admin
   /admin (gerar uma chave)
   /sos?key=SUA_CHAVE
